# WEEKNOTE

iOS 17以降に対応したSwiftUI製のタスク管理アプリです。

## 機能

- 週表示、日付欄の横スクロール、タスクの追加・編集・完了・優先設定・毎日の繰り返し
- 予定の開始時刻・所要時間・場所、完了時刻と「開始前」「時間内」「終了後」の表示
- 習慣の58種類のアイコン、1日の目標、手動記録、継続できるタイマー、週・月・年のグラフ
- 月カレンダー、日別の予定・タスク、日本の祝日
- ライト・ダーク・端末設定の切り替え
- リスト、保存したリンク、検索、完了状態の絞り込み、進捗表示
- 習慣・タスク・予定・リスト・リンクの長押しメニュー
- 週番号、目標日まで、年末まで、開始日からの日数を選べる見出し
- カレンダーの月、習慣グラフの週・月・年、進捗の週を左右スワイプで変更
- 年間の習慣記録を日別の濃淡で表示するヒートマップ
- グラフのタップ位置に縦横の点線と日付・記録時間を表示
- 選択・完了・グラフ・年間記録で共通の緑色のアクセント
- 端末への保存、JSONバックアップの書き出し・読み込み、サイト版からのバックアップ移行

下部タブは「今週」「カレンダー」「進捗」の3つです。リストと設定は、各画面の右上メニューから開きます。日付付きの予定とタスクは共通の一覧へ表示し、日付なしのタスクは「日付なし」を開いて確認できます。

初回はサンプルデータを表示します。設定の「すべてのデータを削除」で空の状態から使えます。データは端末内に保存されます。複数端末間の同期機能はありません。

祝日は[内閣府の公開データ](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)を同梱しています。収録期間は1955〜2027年です。公開された日付のみを表示し、将来の祝日を推測しません。

予定の完了はユーザーの操作で記録します。開始時刻から終了時刻までに完了した場合は「時間内に完了」と表示します。サイト版のデータに完了時刻がない場合は「完了（時刻不明）」を表示します。日付・時刻は端末のタイムゾーンを使います。

タイマーはアプリを閉じている間も経過時間を計算します。終了時に1分未満を切り上げて記録します。未来の日付への習慣記録はできません。

習慣やリストを長押しすると編集・削除などを選べます。削除前には確認画面を表示します。リストを削除すると項目は受信箱へ移動します。習慣を削除するとその習慣の記録も削除します。

習慣・リストの編集画面では、先頭に選択したアイコンとタイトル入力欄を並べます。アイコンを選ぶとキーボードを閉じて先頭へ戻ります。入力欄以外の部分をタップするか、画面をスクロールしてもキーボードを閉じられます。

習慣グラフをタップすると、最も近い棒の位置と値を縦横の点線で示し、日付と記録時間をグラフ内に表示します。週・月は日ごとの分数、年は月合計です。記録が0分の位置も選べます。期間を変更すると選択を解除します。横スワイプによる期間変更と縦スクロールは維持しています。

見出しの「表示」から週番号や日数表示を変更します。週番号は選択日、残日数と経過日数は今日が基準です。目標日と開始日は0日、過ぎた目標日は超過日数、未来の開始日は開始までの日数を表示します。この表示設定は端末内に保存し、タスク・習慣のJSONバックアップとは別に保持します。

カレンダーやグラフは左スワイプで次、右スワイプで前の期間へ移動します。月・期間の表示を長押しすると、前・次への移動も選べます。動きや数値の変化にはアニメーションを付け、端末の「視差効果を減らす」に合わせて動きを抑えます。

## ビルド

MacではXcodeとXcodeGenを使います。

```sh
brew install xcodegen
bash scripts/generate-project.sh
open WEEKNOTE.xcodeproj
```

GitHub ActionsはmainへのpushでiPhone 16 / iPhone SE（第3世代）のテストと、未署名の実機用IPAを生成します。Artifactsから`WEEKNOTE-unsigned-ipa`とテスト結果をダウンロードできます。

**未署名IPAを通常のiPhoneへ直接インストールすることはできません。** 署名済みIPAを生成する手動ワークフローも用意しています。Appleの証明書とプロビジョニングプロファイルの設定が必要です。手順とSecretsの名前は[docs/BUILD.md](docs/BUILD.md)を参照してください。
